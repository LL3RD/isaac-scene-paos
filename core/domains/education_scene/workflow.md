# Education scene workflow

1. Determine whether the reference is a room or a bounded exterior courtyard; do not force an aerial campus into a single-room shell.
2. Use real teaching, student-furniture and play-equipment anchors, with age-appropriate dimensions.
3. Keep evacuation routes, door approaches and circulation around grouped furniture clear.
4. Validate repeated desks/chairs with controlled diversity and verified front axes.
5. If the requested scope is larger than one bounded scene, return a scope observation before generating disconnected proxy buildings.
