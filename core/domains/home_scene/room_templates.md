# Room Templates

这些模板给上层 agent 做 prompt 扩展和资产检索，不是硬编码清单。用户明确指定时以用户为准；用户只说“家居场景”时，优先选择客厅、卧室、厨房、书房之一。

## 客厅 living room

- 推荐尺寸：`4.0m x 3.5m` 到 `7.0m x 5.0m`。
- 大件锚点：sofa、coffee table、TV 或 TV stand、bookshelf/cabinet。
- 功能组合：sofa 面向 coffee table 和 TV；side table 靠 sofa；floor lamp/plant 在角落或 sofa 旁。
- 支撑面小物：remote、book、magazine、cup、vase、decorative bowl。
- 墙面/背景：picture、clock、wall shelf、wall-mounted TV。
- 避免：电视背对 sofa，coffee table 离 sofa 太远，沙发堵门，地面堆太多小物。

## 卧室 bedroom

- 推荐尺寸：`3.2m x 3.2m` 到 `5.5m x 4.5m`。
- 大件锚点：bed、nightstand、wardrobe/closet、dresser。
- 功能组合：bed headboard 靠墙；nightstand 在床一侧或两侧；lamp 放在 nightstand 上；dresser/wardrobe 靠墙。
- 支撑面小物：lamp、book、phone、clock、vase、small box。
- 可选：desk、chair、mirror、plant、picture。
- 避免：床漂在房间中心且无床头朝向，wardrobe 挡住床侧通道，nightstand 离床太远。

## 厨房 kitchen

- 推荐尺寸：`3.0m x 3.0m` 到 `6.0m x 4.5m`。
- 大件锚点：counter/cabinet、refrigerator、sink、stove/oven、kitchen island 或 dining table。
- 功能组合：冰箱、水槽、炉灶形成合理工作三角；counter 靠墙或成 L/U 形；餐椅面向 dining table。
- 支撑面小物：plate、bowl、mug、knife、cutting board、pot、pan、jar、coffee maker。
- 墙面/背景：wall cabinet、shelf、clock。
- 避免：refrigerator 挡住通道，炉灶/水槽孤立在房间中央，餐椅不面向桌子。

## 书房 / 家庭办公室 study or home office

- 推荐尺寸：`2.8m x 3.0m` 到 `5.0m x 4.0m`。
- 大件锚点：desk、office chair、bookshelf、cabinet。
- 功能组合：chair 面向 desk；monitor/laptop/keyboard 放在 desk 上；bookshelf 靠墙；lamp 放在 desk 或 side table 上。
- 支撑面小物：book、notebook、pen holder、cup、keyboard、mouse、monitor、lamp。
- 可选：plant、picture、clock、sofa/chair 阅读角。
- 避免：chair 和 desk 分离，desk 面向墙但椅子被墙挡住，书架空空。

## 餐厅 dining room

- 推荐尺寸：`3.0m x 3.0m` 到 `6.0m x 4.5m`。
- 大件锚点：dining table、chairs、sideboard/cabinet。
- 功能组合：chairs 围绕 table，全部面向 table；sideboard 靠墙；餐具放桌面。
- 支撑面小物：plate、bowl、cup、fork、spoon、vase、fruit bowl。
- 避免：椅子不围绕餐桌，餐桌堵门，桌面完全空。

## 浴室 bathroom

- 推荐尺寸：`2.0m x 2.0m` 到 `4.0m x 3.0m`。
- 大件锚点：sink/vanity、toilet、shower/bathtub、cabinet。
- 功能组合：mirror 在 sink 上方；toiletries 在 vanity/cabinet 上；towel rack 靠墙。
- 支撑面小物：soap、toothbrush cup、bottle、towel。
- 避免：小物直接散落地面，toilet 与 sink/door 严重重叠。
